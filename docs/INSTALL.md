# Install guide

How to add Factory to a project and what gets created on disk.

## Prerequisites

- Git repository (local or remote)
- [Cursor](https://cursor.com) 3.3+ with Agent mode
- Git access to `https://github.com/eskobar95/factory.git` (public — HTTPS works without SSH keys)
- pnpm-based project recommended (hooks assume `pnpm typecheck`, `lint`, `test`)

## First install

Run from **your project root** (not from inside the factory kit repo):

```bash
git submodule add https://github.com/eskobar95/factory.git .factory/kit
./.factory/kit/install.sh
```

### What `install.sh` does

1. **Creates workspace** under `.factory/` (if missing):
   - `context/` — PRD, TECHSPEC, CONTEXT, ADR/, STACK
   - `planning/` — milestones, sprints, tasks
   - `logs/` — diary, decisions
   - `skills/` — project-specific skill overrides

2. **Scaffolds templates** (only if files don't exist — never overwrites your edits)

3. **Links `.cursor/`** to the kit:
   - `.cursor/rules` → `.factory/kit/rules`
   - `.cursor/commands` → `.factory/kit/commands`
   - `.cursor/hooks` → `.factory/kit/hooks`
   - `.cursor/hooks.json` → `.factory/kit/hooks/hooks.json`
   - `.cursor/skills/factory` → `.factory/kit/skills`
   - `.cursor/skills/project` → `.factory/skills` (when populated)

4. **Updates `.gitignore`** — ignores `.cursor/` symlinks (regenerated on install)

5. **Migrates legacy `.ai/`** → `.factory/` if present

### What to commit

| Path | Commit? | Why |
|------|---------|-----|
| `.factory/kit` | Yes | Submodule pointer |
| `.factory/context/` | Yes | Your PRD, specs, ADRs |
| `.factory/planning/` | Yes | Milestones, sprints, tasks |
| `.factory/logs/` | Optional | Diary — often gitignored per project |
| `.factory/skills/` | Yes | Project skill overrides |
| `.cursor/` | No | Symlinks — regenerated by install |

Add to `.gitignore` if you don't want diary in git:

```gitignore
.factory/logs/
```

## Clone an existing project

```bash
git clone git@github.com:you/your-project.git
cd your-project
git submodule update --init --recursive
./.factory/kit/install.sh   # refresh symlinks
```

## Update the kit

```bash
./.factory/kit/update.sh
git add .factory/kit
git commit -m "chore: update factory kit"
```

Or in Cursor: `/factory-update`

## Verify install

```bash
# Symlinks exist
ls -la .cursor/rules .cursor/commands .cursor/hooks .cursor/skills/factory

# Workspace scaffold
ls .factory/context .factory/planning .factory/logs

# Submodule on latest
git -C .factory/kit log -1 --oneline
```

## Troubleshooting

### "Run from your project root"

You ran `install.sh` from inside the factory repo itself. `cd` to your app project first.

### Broken symlinks after `git clean`

Re-run `./.factory/kit/install.sh` or `./.factory/kit/update.sh`.

### Hooks not firing

Confirm `.cursor/hooks.json` is a **symlink** (not a copied file). Re-run update.

### Legacy layout (`.factory` was the submodule)

See [MIGRATION.md](MIGRATION.md).
